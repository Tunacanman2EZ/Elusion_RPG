GAME ELUSION (Godot 4)
College Project Proposal

Project Overview
Game Elusion is a 2D RPG inspired by classic favorites, enhanced with modern gameplay features:
* Challenging level progression
* World bosses, secret bosses, and rare loot drops
* Randomized attributes on loot for variety
* Collectable pets that can attack
    * Deep skill system by player roles (tank, healer, mage, warrior, support)
    * Skills activated by chat commands
    * Unique skills with long cooldowns for group events
    * Top-tier abilities learned via rare scrolls or achievements
* Player professions: mining, fishing, and more
* In-game economy: shop, loot selling, currency, gacha-style paid area
* Keycards and boss runs with rare chest rewards
* Plans for new characters and skills as content grows
